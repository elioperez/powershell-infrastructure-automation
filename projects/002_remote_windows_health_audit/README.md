# Project 002 — Remote Windows Health Audit

## Objective

Perform an automated health and security audit of a remote Windows endpoint using PowerShell Remoting.

## Environment

### Controller

- Host machine
- PowerShell Core

### Target

- Windows 10
- IP: 192.168.56.128

## Technologies

- PowerShell
- WinRM
- PowerShell Remoting

## Health Checks

- Operating System
- CPU
- RAM
- Disk Usage
- Firewall Status
- Windows Defender
- Local Administrators
- RDP Status

## Outputs

- TXT Report
- CSV Report
- JSON Report

## Skills Demonstrated

- Remote Administration
- Security Auditing
- Endpoint Assessment
- Reporting Automation
